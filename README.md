# Paisainstant DSA Landing Page

1. Create a GitHub repository named `Paisainstant-DSA`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Put your banner images in `images/` as `banner1.jpg`, `banner2.jpg`, `banner3.jpg`.
4. Repository Settings -> Pages -> Deploy from branch -> `main` -> `/ (root)` -> Save.
5. Your site will be available at:
https://paisainstantlogin-oss.github.io/Paisainstant-DSA/

The links in `index.html` already contain the UTM/login URLs supplied for this page.
